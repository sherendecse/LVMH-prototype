# Makeup Look Advisor Prototype

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Prototype behavior

- Four free-text questions
- 75% occasion weighting
- 25% boldness weighting
- Skin-type product filtering
- Avoidance keyword filtering
- Dynamic simulated makeup preview
- Editable look details and intensity
- Complete routine selection
- Browser local-storage saving

## Important

The product catalogue in this prototype uses sample names and sample prices.
Replace it with verified official Fenty Beauty product records before publishing.
